You interact with your Bezi agent via Threads. They belong to a Workspace, write to the target project and pull context from multiple places. Using threads correctly is very important.

<Frame>
  ![Image](/images/image.png)
</Frame>

## How Threads gather and manage context

1. Active Thread prompt and response history (it cannot access other thread's histories)
2. Active [Workspace Connections](https://docs.bezi.com/context/connections); projects and local data sources you've connected. Target project context is prioritized.
3. [Pages](https://docs.bezi.com/context/pages), both private and shared 

Monitor the **thread's context window tracker** (bottom right of the prompt field). Lower context windows = better results and fewer credits used per prompt.

If the context window is high, disable unnecessary Connections or start a new thread.

## How Threads interact with Workspaces

Threads are stored at the Workspace level, not the project level. **Threads list shows all thread you've created in the Workspace.**

If you switch Workspaces, the Threads list will change. You will only see threads that belong to the new Workspace.

## How Threads interact with engine projects

For every new thread, you assign **target project**. This tells the Bezi agent what to make edits to and use for primary context. Click the **Project selector** to select a target project from your Connections.

<Warning>
  Do not change a thread's target project once you've prompted in that thread. This leads to unexpected behavior and changes. 
</Warning>

## Threads navigation

Everything Threads-related lives in the right sidebar, i.e. the ‘**Threads window**’. This is where you create new threads, access old threads, and manage all threads associated with a Workspace.

Open the **Threads** dropdown in the right sidebar to see a list of your past threads in the current Workspace. Each entry shows the thread name and its target project so you can quickly identify what you were working on.

From this menu you can:

- Open a past thread to continue where you left off
- See which target project each thread is associated with
- Delete threads you no longer need

If you can't find a specific thread, confirm that you're looking in the right Workspace.
