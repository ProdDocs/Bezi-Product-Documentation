---
title: "Prompt Attachments"
---

Attachments are an easy way to give your Bezi agent extra references for a given task. 

In the case of visual tasks, like implementing UI or updating a level, we strongly suggest providing visual references for your agent to copy. 

## Using attachments

If your prompt includes image attachments, include instructions on:

1. What part of the image(s) Bezi should focus on
2. What information Bezi should gather or look for
3. What Bezi needs do with the information

A prompt can have 3 or fewer attachments. 

## How to upload

**There are two ways to attach an image:**

1. Drag/drop it into the prompt box
2. Click the attachment icon in the prompt box and select the file

**Upload specs**:

- Max file size: **5 MB** and **8000x8000 px**
- Supported image file formats: **JPEG**, **PNG**, **WebP**, and **GIF**
- GIFs are a collection of images, so Bezi can only analyze the first frame
- Text files are supported
